# Into the Climb: Training — технічна специфікація

Версія 1.0, вересень 2026. Цей документ фіксує всі рішення щодо застосунку. Додавайте його на початку кожного нового чату про проєкт, щоб Claude мав повний контекст.

Дизайн: [концепт 0.2](https://claude.ai/artifact/3yoxjsE7FDvv6QU8DXEKUV)

## 1. Що це

PWA для онлайн-тренувань скелелазів за індивідуальною програмою. Тренер (Ілля) складає план для кожного учня, учні виконують його і відмічають результати. Орієнтовно до 25 учнів. Застосунок є частиною екосистеми бренду Into the Climb (туристична агенція, виїзди на скелі).

## 2. Технології

| Частина | Вибір | Чому |
|---|---|---|
| Інтерфейс | React + TypeScript + Vite | Стабільний стандарт, багато готових рішень |
| PWA | vite-plugin-pwa | Встановлення на головний екран, кеш, оновлення |
| Навігація | React Router | Екрани та кнопка «назад» |
| Дані й кеш | TanStack Query | Кешування, повторні спроби, основа для офлайн-режиму |
| Бекенд | Supabase | База Postgres, авторизація, сховище файлів, правила доступу |
| Редактор матеріалів | Tiptap | Текст з форматуванням, фото, посилання |
| Хостинг | Vercel | Безкоштовно, автоматичний деплой з GitHub |
| Код | GitHub | Зберігання коду та історія змін |

Безкоштовних тарифів Supabase і Vercel для 25 користувачів достатньо.

## 4. Ролі та доступ

Вхід для всіх через email і пароль. Скидання пароля відбувається через лист.

**Тренер.** Акаунт створюється вручну, роль `coach` виставляється в базі. Можна додати кількох тренерів. Кожен учень закріплений за тренером (`coach_id`). Тренер бачить і редагує дані своїх учнів, бібліотеку та матеріали.

**Учень.** Реєструється сам і отримує статус `pending`. Поки тренер не натисне «Прийняти», учень бачить лише екран очікування. Після цього отримує статус `active`.

Учень може:
- редагувати свій профіль, крім ролі, статусу і нотатки тренера;
- бачити лише свої тренування;
- у тренуванні змінювати тільки час початку і кінця, відмітки розминки, результат і коментар до вправ, а також відмітку «виконано»;
- створювати й видаляти тільки власні фан-тренування.

Учень не може змінювати тип тренування, вправи і пункти розминки. Ці обмеження перевіряються в базі даних (RLS і тригери), а не лише в інтерфейсі.

## 6. Розрахунки на дашборді учня

- **Наступне тренування.** Найближче не фан і не виконане тренування з датою від сьогодні.
- **Місячний план.** Кількість виконаних тренувань (не фан) з усіх запланованих у поточному місяці. Показується як маршрут із зачіпок.
- **Розбивка за типами.** Та сама пропорція окремо для кожного типу. Для фану показується кількість сесій і годин.
- **Години в залі.** Сума (кінець − початок) по всіх виконаних тренуваннях місяця, включно з фаном.

## 7. Екрани

**Учень:** реєстрація, очікування підтвердження, дашборд, календар, сторінка тренування (з кнопкою фан-тренування), матеріали, стаття.

**Тренер:** вхід, дашборд (заявки й список учнів), сторінка учня (нотатка й календар), редактор тренування, бібліотека (вправи й розминки), редактор шаблону, матеріали, новий або редагований матеріал.

На всіх екранах, крім входу й реєстрації, є таб-бар. На вкладених екранах є кнопка «назад».

## 8. План робіт

**Етап 0. Підготовка.** Ілля створює акаунти на GitHub, Supabase і Vercel.

**Етап 1. Фундамент.** Створюємо проєкт, базові компоненти дизайну і структуру бази з правилами доступу. Робимо вхід, реєстрацію і підтвердження учня тренером.

**Етап 2. Тренер.** Дашборд, сторінка учня, редактор тренування, бібліотека.

**Етап 3. Учень.** Календар, сторінка тренування, фан-тренування, дашборд з розрахунками.

Після етапу 3 застосунком уже можна користуватись.

**Етап 4. Матеріали.** Список, фільтр, редактор, фото.

**Етап 5. PWA.** Встановлення, офлайн-режим для сторінки тренування, push-нагадування (на iPhone працюють лише для встановленого застосунку, iOS 16.4+).

## 9. Рішення після Етапу 5

- **Боулдеринг і скелі:** окремо не додаємо. Профіль має лише французьку шкалу (RP/онсайт) для зали.
- **Адреса застосунку:** піддомен сайту Into the Climb (не vercel.app). Точний піддомен і DNS-налаштування — коли Ілля назве домен агенції.
- **Копіювання тижня:** не додаємо. Тренер створює кожне тренування окремо через редактор, як зараз.

## 10. Відкриті питання

- Точна назва домену Into the Climb і бажаний піддомен (наприклад, `training.<домен>`) — для прив'язки в Vercel.
